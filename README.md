# Luxus — Introducer Programme Deck (GitHub-ready)

Self-contained 8-slide presentation (Graphite Noir) for the Introducer Programme.
All assets are inlined into `index.html` — no build step, works offline (fonts load from
Google Fonts when online; otherwise falls back to system serif/sans).

## Deploy on GitHub Pages
1. Upload the **contents of this folder** to the repo root (just `index.html`).
2. Repo **Settings → Pages → Deploy from a branch**.
3. Branch **main**, folder **/ (root)**, then **Save**.
4. Live at `https://<username>.github.io/<repo>/` in ~1 minute.

## Using the deck
- Click the slide (or the on-screen ‹ › control) to advance; ← → keys work too.
- On touch devices, tap the right/left side to go forward/back.
- Print to PDF from the browser for a one-page-per-slide handout.
